Section 1: Project-based questions
1. What is Memento?

Memento is an AI-powered document knowledge management system. It allows users to upload documents such as PDF, DOCX and TXT, ask questions about their contents and receive AI-generated answers with source citations.

2. What problem does your project solve?

It reduces the time required to search through large documents. Instead of manually reading every page, users can ask questions and get relevant answers from their uploaded documents.

3. What is the technology stack used?
- Frontend: React 19, TypeScript, Tailwind CSS.
- Backend: Java 21, Spring Boot 3.
- Database: PostgreSQL.
- Vector search: pgvector.
- AI integration: Spring AI.
- AI models: Qwen 2.5 3B and Nomic Embed Text.
- State management: Zustand.
- Build tools: Maven and Vite.
4. Explain the architecture of Memento.

Memento follows a layered full-stack architecture.
1. React handles the user interface.
2. Spring Boot handles REST APIs and business logic.
3. PostgreSQL stores application data.
4. pgvector performs vector similarity search.
5. Spring AI integrates AI models.
6. Ollama runs AI models locally.
5. Explain the complete working flow of Memento.
1. User logs in.
2. User uploads a document.
3. Backend extracts the document text.
4. Text is divided into chunks.
5. Embeddings are generated.
6. Embeddings are stored in pgvector.
7. User asks a question.
8. The question is converted into an embedding.
9. Similar document chunks are retrieved.
10. The AI model generates an answer using the retrieved content.
6. Why did you choose Spring Boot?

Spring Boot simplifies backend development through dependency injection, auto-configuration, REST API support, database integration and security support.

7. Why did you choose React?

React provides reusable components, efficient UI updates, hooks and a component-based architecture.

8. Why PostgreSQL instead of MySQL?

PostgreSQL provides strong relational database features and supports the pgvector extension, which allows us to perform vector similarity searches in the same database.

- Streaming AI responses.

Section 2: Java and Spring Boot
11. What is Spring Boot?

Spring Boot is a Java framework used to develop standalone, production-ready applications with minimal configuration.

12. What is dependency injection?

Dependency Injection is a design pattern in which an object's dependencies are provided by the Spring container rather than created manually.

Example:
@Service
public class DocumentService {
    public void process() {
        System.out.println("Processing document");
    }
}


@RestController
public class DocumentController {

    private final DocumentService service;

    public DocumentController(DocumentService service) {
        this.service = service;
    }
}


Here, Spring injects DocumentService into DocumentController.

Section 3: RAG and Artificial Intelligence
Very important for Memento
21. What is Artificial Intelligence?

AI is a field of computer science that enables machines to perform tasks that typically require human intelligence, such as understanding language, recognizing patterns and making decisions.

22. What is an LLM?

LLM stands for Large Language Model. It is an AI model trained on large amounts of text to understand and generate human language.

Example: Qwen.

23. What is RAG?

RAG stands for Retrieval-Augmented Generation.

It combines information retrieval with AI text generation. The system retrieves relevant information from an external knowledge source and provides it to an LLM to generate a context-aware answer.

24. Why did you use RAG instead of directly using an LLM?

An LLM may not know the contents of a user's private documents. RAG retrieves relevant information from those documents and provides it as context, allowing the model to answer document-specific questions.

25. What is an embedding?

An embedding is a numerical representation of text in vector form.

For example:
"Java is a programming language"
             |
             v
       Embedding Model
             |
             v
[0.21, 0.45, 0.78, 0.12, ...]


Similar meanings generally produce vectors that are close in vector space.

26. What is semantic search?

Semantic search finds information based on meaning rather than only matching exact keywords.

For example:

Question: "How does Java manage memory?"

A semantic search can retrieve content about JVM garbage collection even if the exact question words are absent.

27. What is chunking?

Chunking means splitting a large document into smaller text sections.

Example:
100-page PDF
      |
      v
Text extraction
      |
      v
Chunk 1
Chunk 2
Chunk 3
Chunk 4
      |
      v
Embedding generation


It makes document retrieval more efficient and provides focused context to the LLM.

28. What is the difference between an embedding model and a generative model?
Embedding model	Generative model
Converts text into vectors	Generates text
Used for semantic search	Used for answering questions
Nomic Embed Text	Qwen 2.5 3B

29. What is hallucination in AI?

Hallucination occurs when an AI model generates incorrect or fabricated information while presenting it as factual.

RAG can help reduce hallucination by providing relevant document context, but it cannot guarantee that every answer is correct.

30. What is prompt engineering?

Prompt engineering is the process of designing instructions and context to guide an AI model toward producing useful and accurate responses.

31. What is Ollama?

Ollama is a tool that allows developers to download and run supported AI models locally.

32. What is Spring AI?

Spring AI is a Java framework that provides abstractions for integrating AI models, embedding models, vector stores and retrieval workflows into Spring applications.

33. What is the difference between RAG and fine-tuning?
RAG	Fine-tuning
Retrieves external information	Changes model behavior through additional training
Knowledge can be updated by changing documents	Requires additional training
Useful for document-based Q&A	Useful for adapting model behavior or task patterns

34. What is top-K retrieval?

Top-K retrieval selects the K most relevant document chunks for a particular question.

For example, if K = 5, the system retrieves the five most similar chunks.

35. What is cosine similarity?

Cosine similarity measures the similarity between two vectors based on the angle between them.
\[
\text{Cosine Similarity} =
\frac{A \cdot B}{\|A\|\|B\|}
\]

A value closer to 1 generally indicates greater directional similarity.

43. What is a foreign key?

3. Understanding RAG – The most important concept in Memento
Core AI technology
RAG stands for Retrieval-Augmented Generation.

It combines two operations:
- Retrieval: finding relevant information from documents.
- Generation: using an AI model to generate an answer based on that information.
How RAG works in your project
Document processing pipeline
1. Document upload
   
   User uploads PDF, DOCX or TXT through React.
2. Text extraction
   
   Spring Boot extracts readable text from the uploaded document.
3. Text chunking
   
   The extracted text is divided into smaller pieces called chunks.
   
   Example: 10,000 words become multiple smaller text sections.
4. Embedding generation
   
   nomic-embed-text converts each chunk into a numerical vector representing its semantic meaning.
5. Vector storage
   
   PostgreSQL with pgvector stores the embeddings and their associated document information.
6. Semantic retrieval
   
   When a user asks a question, the question is converted into an embedding and similar document chunks are retrieved.
7. AI answer generation
   
   qwen2.5:3b receives the question and retrieved context and generates an answer.
8. Source citations
   
   The backend returns the answer along with references to the relevant document content.

Example
Suppose your uploaded document contains:

"Spring Boot is a Java-based framework used to develop standalone, production-ready applications."

You ask:

"What is Spring Boot?"

The process looks like this:
Component	Responsibility
React	Sends your question
Spring Boot	Receives the question
Embedding model	Converts question into a vector
pgvector	Finds relevant document chunks
Qwen model	Generates the answer
Spring Boot	Sends answer and citations
React	Displays the answer

Why not directly ask the AI model?

A normal AI model might answer from its general training knowledge. RAG gives it relevant information from your own uploaded documents, helping it answer document-specific questions and provide citations.

Project: Memento – AI-Powered Document Knowledge Workspace

"My project Memento is an AI-powered document knowledge management system that allows users to upload PDF, DOCX and TXT documents and interact with them through an AI chatbot.
